RECEIVE

Nhập kho (Receive)

Count of Transaction Qty — nhóm theo Kho xuất / Transaction Type / Item / Locator / User. Mặc định lọc Kho xuất = 3B.
—
Kho xuất ↕ Transaction Type ↕ Item ↕ Locator ↕ User Name ↕ Total ↕
Chưa có dữ liệu — hãy tải file Transaction ở trên.
TRANSFER

Chuyển pallet (Transfer)

Sum of Flag — nhóm theo Kho xuất / Menu Name / Item / Locator đến / User / Reference (ghép cặp đúng 2 dòng +/- của cùng 1 Transaction Set ID, không đếm trùng). Các dòng cùng Reference được tính là cùng 1 "Chuyến" — đánh số Chuyến theo thời gian tăng dần, sớm nhất là Chuyến 1. Cùng mã hàng + cùng Chuyến sẽ gộp làm 1 dòng dù pallet nằm ở nhiều vị trí xuất khác nhau (cột Locator xuất liệt kê đủ các vị trí đó). Gồm mọi giá trị Menu Name trong file có tính chất di chuyển (trừ Pick(CSR) — đã tách riêng ở bảng Picking bên dưới). "Kho xuất" đọc trực tiếp từ tồn kho thực tế của Locator xuất. Mặc định lọc Kho xuất = 3B.
—
Kho xuất ↕ Menu Name ↕ Item ↕ Locator xuất ↕ Locator đến ↕ User Name ↕ Số lượng ↕ Chuyến ↕ Total ↕
Chưa có dữ liệu — hãy tải file Transaction ở trên.
PICKING

Lấy hàng (Pick Order)

Sum of Flag — nhóm theo Kho xuất / Locator đến / Item / User (Menu Name = "Pick(CSR)", ghép cặp 2 dòng +/- cùng Transaction Set ID để lấy đúng vị trí lấy hàng thật). "Số lượng cont" đếm số mã CRxxxxx khác nhau trong cột Reference (cùng CR = cùng 1 container) — dòng Grand Total đếm số CR khác nhau trên TOÀN BỘ dữ liệu đang hiển thị, không cộng dồn từng dòng. Mặc định lọc Kho xuất = 3B.
—
Kho xuất ↕ Locator đến ↕ Item ↕ User Name ↕ Số lượng cont ↕ Total ↕
Chưa có dữ liệu — hãy tải file Transaction ở trên.
ITN

Xe Trung Chuyển

2 bảng song song — bên trái là Menu Name "ITN Transfer" (Chuyển đi), bên phải là "ITN Receiving" (Nhận). Mỗi bảng gộp nhóm theo Item / Locator đến / Chuyến (các dòng cùng Reference tính là cùng 1 Chuyến) — chỉ giữ 1 cột vị trí ổn định (bãi ITN), bỏ cột vị trí lưu trữ lẻ tẻ hay đổi. Chuyến được đánh số dùng chung cho cả 2 bên (theo thời gian tăng dần) để dễ đối chiếu Chuyển đi khớp với Nhận.
