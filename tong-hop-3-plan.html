Trang này luôn lấy dữ liệu trực tiếp từ Cloud — cần kết nối trước khi xem.

Kết nối Cloud

Nhập đúng thông tin Cloud (Firebase) đang dùng ở TN5 Dashboard để xem Plan/Container mới nhất. Thông tin chỉ lưu trên máy này (trình duyệt), không gửi đi đâu khác ngoài đúng địa chỉ Cloud bạn nhập.

Lấy thông tin này trong app TN5 Dashboard chính, mục "Kết nối Cloud" (⚙️ Cài đặt).
